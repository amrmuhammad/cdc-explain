# cdc-explain

AI-powered root-cause explanation for clock domain crossing (CDC) bugs – free and open-source, built for the Verilator ecosystem.

## Overview
`cdc-explain` takes a Verilator simulation VCD, log, and CDC report and uses a large language model (LLM) to explain *how* a structural CDC violation caused a specific simulation failure.
