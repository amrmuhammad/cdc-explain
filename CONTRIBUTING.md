# Contributing to cdc-explain

Thank you for your interest! This project is part of an open-core model: the core engine and Verilator integration are MIT-licensed and community-driven. Premium features (commercial parsers, fine-tuned models, VS Code extension) are closed-source and commercially licensed.

## How to contribute
- **Bug reports & feature requests**: Open an issue.
- **Code contributions**: Fork, branch, and open a pull request against `main`.
- **Documentation**: Improvements, examples, and tutorials are hugely welcome.
- **Community**: Join the discussion in the Verilator / YosysHQ communities.

## Development setup
1. Clone the repo
2. `python -m venv .venv && source .venv/bin/activate`
3. `pip install -r requirements.txt`
4. Run tests with `pytest`

We follow a simple code of conduct: be respectful, helpful, and inclusive.
